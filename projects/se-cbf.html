Super-Ellipse Control Barrier Functions for Enhanced Obstacle Avoidance in Complex Multi-Agent Environments

Overview

My undergraduate thesis studies safe navigation for mobile robots in multi-robot environments: avoiding collisions while keeping traffic moving efficiently. Control barrier functions (CBFs) are a standard tool for real-time safety, but they usually use a circular safety boundary. Around rectangular obstacles that boundary is too conservative: it blocks free space the robot could actually use and forces unnecessary detours. SE-CBF uses a super-ellipse boundary that fits the obstacle's real shape, cutting out those detours.

Method

  • Perception. A fixed overhead camera and OpenCV detect obstacles with color-threshold segmentation and bounding boxes. A pixel-to-world mapping then converts each detection into a 2D global frame with its origin at the center of the arena, giving the obstacle's position and size.
  • Safety constraints. The position and size of each obstacle define a super-ellipse CBF constraint that matches its footprint.
  • Control. A quadratic program (QP) optimizes the robot's navigation command so that it satisfies every safety constraint while staying as close as possible to the original motion toward the goal.
  • System. Everything is built on ROS and was tested both in Gazebo and on real robots.

Results

In a dense multi-robot intersection, SE-CBF cut the task completion time from 123 s to 62 s compared with the standard circular CBF, a clear gain in traffic efficiency with the same safety constraints.

What I did

  • Built the camera-based perception pipeline: OpenCV segmentation, bounding-box detection and pixel-to-world mapping.
  • Designed the super-ellipse CBF formulation and implemented the QP-based navigation controller.
  • Built the system on ROS and ran the experiments in Gazebo and on real robots.

The project gave me hands-on experience in ROS development, vision-based localization, robot safety control, and taking a system from simulation to real hardware.
